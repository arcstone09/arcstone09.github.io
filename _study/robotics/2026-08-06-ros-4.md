# ROS2 Workspace

ROS에서 패키지는 기능을 구현하는 가장 작은 단위이고, 워크스페이스는 여러 개의 패키지를 모아 관리하는 작업 공간이다.

colcon은 ROS 2 프로젝트를 빌드(build)하기 위한 도구이다. 다음 명령어로 설치한다.

```bash
sudo apt install python3-colcon-common-extensions 
```



예를 들어, 다음과 같은 프로젝트 구조를 생각하자.

```scss
ros2_ws/
 ├── src/
 │    ├── my_robot
 │    ├── my_msgs
 │    └── camera_node
```

- `colcon build`를 하면 현재 워크스페이스 안의 모든 ROS 패키지를 컴파일한다. 실행하면, build/, install/, log/ 디렉터리가 생기는데, 각각 컴파일 중간 파일, 실행 가능한 결과물, 빌드 로그를 담는다.
- `~/.bashrc` 에 `source ~/ros2_ws/install/setup.bash` 를 추가하여, 내가 방금 빌드한 패키지를 ROS가 인식하도록 한다.
