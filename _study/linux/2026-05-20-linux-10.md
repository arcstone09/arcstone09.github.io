In this post, how to use Jupyter notebook in SSH server is introduced.



# Jupyter Notebook on Server

```bash
# 서버로 SSH 접속
ssh -p 2224 student@147.46.78.16

# 서버 8888 port에서 jupyter notebook 실행
jupyter notebook --no-browser --ip=0.0.0.0 --port=8888 # 토큰 값 확인

# 로컬 새 터미널에서 내 컴퓨터의 8888 포트를 서버의 8888 포트와 연결(port forwarding)하면서 SSH 접속
# -L [내포트]:[서버주소]:[서버포트]
ssh -L 8888:localhost:8888 -p 2224 student@147.46.78.16
```



```scss
내 브라우저 localhost:8888 하여 token 값 입력하면 됨.
↓
내 컴퓨터 8888 포트
↓ (SSH 터널)
서버 8888 포트
↓
서버에서 실행 중인 Jupyter
```
