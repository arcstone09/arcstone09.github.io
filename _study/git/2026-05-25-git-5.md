# Git log

```cmd
git log --oneline --graph --all --decorate
```

- `*` : 커밋 노드
- 가지 갈라짐/합쳐짐이 선으로 표시됨
- 어떤 브랜치가 어디서 분기됐는지 확인 가능



```cmd
# 브랜치 구조를 트리처럼 보기
git show-branch
```
